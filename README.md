# punchrss

Punch and reshape rss text streams with deterministic transforms.

**Site:** https://theworker02.github.io/punchrss/

## Install / run

```bash
git clone https://github.com/theworker02/punchrss.git
cd punchrss
node src/cli.js
node --test
```
