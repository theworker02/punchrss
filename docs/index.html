Overview

Punch and reshape rss text streams with deterministic transforms. Built as a tiny zero-dependency Node toolkit with a library API and a stdin-friendly CLI.

Usage

git clone https://github.com/theworker02/punchrss.git
cd punchrss
node src/cli.js --help
node --test
